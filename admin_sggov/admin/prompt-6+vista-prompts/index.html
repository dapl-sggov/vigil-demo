Sobre este ecrã

Os prompts são imutáveis e versionados: alterar um prompt é criar uma versão nova. Ativar uma versão desativa a que estava ativa no mesmo módulo, de modo que há sempre uma só ativa por módulo.

Quem escreve aqui é a DAPL, que mantém prompts, catálogos, perfis e retroplano; a supervisão da SGGov só lê.
