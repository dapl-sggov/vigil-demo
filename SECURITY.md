# Política de Segurança · `vigil-demo`

> Este repositório contém **apenas o mock interactivo** do VIGIL — HTML/CSS/JS estático sem backend, sem IA real, sem dados sensíveis. Não há informação classificada nem credenciais nesta base de código.

## Reportar uma vulnerabilidade

Se descobriste uma vulnerabilidade neste repositório ou no VIGIL em geral, por favor reporta privadamente:

- **Canal preferido:** abrir issue privado via [Security Advisories](../../security/advisories/new) deste repositório
- **Alternativa:** e-mail `security@sggov.gov.pt` (a publicar)
- **Encriptação:** chave PGP do responsável de cibersegurança em `.well-known/security.txt` (em curso)

A política completa de Coordinated Vulnerability Disclosure está documentada na pasta institucional do projecto VIGIL (`06_Seguranca_NIS2/03_Politica_CVD.md`).

## Compromissos

| Marco | Prazo |
|-------|-------|
| Acuso de recepção | 2 dias úteis |
| Triagem inicial | 5 dias úteis |
| Plano de remediação | 15 dias úteis |
| Correcção (CVSS ≥ 7.0) | 90 dias |

## Safe harbour

A SGGov compromete-se a **não accionar judicialmente** investigadores que actuem de boa-fé e dentro do âmbito da política CVD.

## Âmbito específico deste repositório

| In-scope | Out-of-scope |
|----------|--------------|
| Páginas HTML deste repo | Sistemas de produção VIGIL (não existem ainda) |
| URL público do GitHub Pages | Engenharia social |
| Workflows GitHub Actions | DoS volumétrico contra GitHub |

## Quadro legal
